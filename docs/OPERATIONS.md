# VYNTRIO workspace operations

This project upgrades the existing Vercel landing page to a single-agency client portal. It is not a billing platform for selling subscriptions to other agencies.

## Accounts and roles
- Owner: the verified account matching ADMIN_EMAIL. Bootstrap grants owner only after Supabase confirms mailbox ownership.
- Admin: manages clients, inquiries, projects, financial records, exports, notifications and backups.
- Staff: accesses assigned projects, shared/internal updates, milestones, files and support. Cannot manage agency finances, invite clients, or grant access.
- Client: accesses only their projects and associated records. Only the project client can approve milestones or respond to quotations.
- Staff/owner/admin must complete authenticator MFA in production. Database policies also enforce MFA for staff access.
- Disable public signups in Supabase Auth. Account creation happens through the protected admin invitation flow. No public role-selection form exists.

## Service setup
1. Supabase: run migrations in order; use the project URL, publishable key, and server secret in private Vercel environment settings. Never prefix a server secret with NEXT_PUBLIC_. Auth site URL and allowed redirect must match the chosen deployment URL and /auth/confirm.
2. Google: create a separate Apps Script project with integrations/SaaSBridge.gs. Run setupBridge as the owner and review Google permissions for sending email, the private delivery log, the legacy sheet, and private Drive backups. Deploy as yourself with Anyone access; every sensitive request requires an HMAC and a fresh timestamp. Copy SAAS_BRIDGE_SECRET to Vercel EMAIL_BRIDGE_SECRET and use the new /exec URL as EMAIL_BRIDGE_URL. Keep the existing inquiry Apps Script project unchanged.
3. Spam protection: create a Cloudflare Turnstile widget for the exact website hostname. Save the site key publicly and the secret server-side. Production validation fails closed without a valid token.
4. Cashfree: use Production credentials only in private Vercel settings. Keep the payment-form webhook and add a Payment Gateway success webhook at /api/cashfree-webhook for the new server-created orders. Validate a real payment with the owner; never mark paid from the return page. Test mode uses separate credentials and sandbox checkout.
5. Private server secrets: RATE_LIMIT_SALT, PAYMENT_LINK_SECRET, CRON_SECRET should each be at least 32 random bytes. BACKUP_ENCRYPTION_KEY must be 32 random bytes encoded as base64. Keep an offline recovery-key copy; losing it makes encrypted backups unrecoverable. These secrets must not be committed, logged, or sent in chat.

## Email behavior
Login links are generated by Supabase and delivered directly through the private Google bridge; tokens are not stored in the notification outbox or exposed to staff. Normal notifications use a persistent, retryable outbox and unique event keys. An email failure does not roll back an already saved inquiry. The Google bridge logs message IDs and timestamps to reduce duplicate delivery.

Consumer Google accounts currently have a quota of 100 recipient deliveries per day (provider limits can change). Owner and client copies both count. The default daily maintenance retries failed messages; admins can retry pending messages in the workspace. Immediate delivery is attempted after actions. For larger volumes or reliable rapid retries, configure a verified-domain email provider and a more frequent scheduler. Do not promise zero delay or guaranteed inbox placement.

## Backups and restoration
Database snapshots are compressed and encrypted using AES-256-GCM. They are stored in a private Supabase bucket and copied to a private Google Drive folder. New uploaded files are backed up individually; daily/manual runs retry one pending file. A run with remaining unprotected files is marked failed/needs attention rather than claiming full coverage. Thirty days of database snapshots are retained. Project-file copies are retained separately.

The scheduled daily maintenance endpoint requires CRON_SECRET. It runs in production only. Vercel Hobby scheduling is daily with approximate timing; this is not a minute-level retry system. Snapshots are bounded to 100,000 rows per table and a compressed/encrypted 3 MB bridge payload. File uploads are capped at 3 MB. Larger workloads need managed backup infrastructure and a different upload path.

Use `npx tsx scripts/restore-backup.ts /path/to/database.vyn --confirm-empty-target` against a new, empty target with migrations installed. Set recovery/target secrets privately. BACKUP_SOURCE_URL and BACKUP_SOURCE_SECRET_KEY point to the backup source if different. Restoration recreates passwordless identities, maps account IDs, restores application tables and separate file copies, and requires fresh MFA enrollment. It does not restore old sessions or Supabase provider configuration. Unsent historical notifications are suppressed for manual review. Test this process before relying on backups; local encryption tests alone do not prove a full production restore.

## Existing records and Google Sheets
Settings → Import earlier records reads the original private sheet through the signed Google bridge. Inquiry references are preserved, repeated imports do not duplicate records, and earlier payments are checked with Cashfree's authenticated API. Editable spreadsheet payment text alone is not trusted. Fix any failed or unmatched record in the review workflow after checking Cashfree.

The database is authoritative. The original Inquiries and CashfreePayments tabs remain legacy records. Settings → Update Sheets report creates separate SaaS_Inquiries, SaaS_Projects and SaaS_Payments tabs; editing those copies does not change portal records. CSV exports are available and escape spreadsheet-formula prefixes. Paise amounts are integer minor units.

## Safe rollout
Keep the existing main deployment until the upgrade is configured and tested. Push the upgrade branch for preview. Test owner login/MFA, a client invitation, cross-client denial, a project/milestone approval, a private-file upload/download, notifications, verified payment, a backup and a restore. Reconcile imported totals and open invoices. Only then promote the same tested commit to the production site. Retain the prior commit for rollback. Do not run both new and old project-payment workflows for the same invoice.

## Free-plan limits
- Vercel Hobby is intended for personal/non-commercial use. Confirm the account plan before commercial production; this code does not purchase or upgrade it.
- Supabase Free can pause low-activity projects and does not provide the same managed-backup coverage as paid plans.
- Google email and Apps Script have daily/execution quotas. Failed notifications and backup jobs need monitoring.
- No uptime, delivery-speed, automatic-refund, bank-settlement, or tax-compliance guarantee is implied.
